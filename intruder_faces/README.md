# Intruder Faces

This folder contains sample images of unauthorized individuals used for testing the intruder detection pipeline.

These images are provided only as example data. Replace them with your own test images when using the application.

Example:

intruder_faces/
├── intruder1.jpg
├── intruder2.jpg
└── intruder3.jpg

Supported formats:

- JPG
- JPEG
- PNG
